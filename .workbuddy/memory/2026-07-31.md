# 2026-07-31
- 为 selected-ai 项目编写 install.sh：用 xcodebuild 以 -target selectedai 构建（无共享 scheme，故按 target 构建），禁用签名（CODE_SIGN_IDENTITY="-" / CODE_SIGNING_REQUIRED=NO / CODE_SIGNING_ALLOWED=NO），产物拷贝到 INSTALL_DIR（默认 /Applications，可用 env 覆盖），并 xattr 去 quarantine。
- 调试 selected-ai 工具框不弹:根因是未签名(app用 CODE_SIGN_IDENTITY="-" 即席签名)导致辅助功能(TCC)授权在每次重新构建后失效;且授权引导仅弹一次。已修复 SelectionMonitor 新增 reregister()/teardownObserver(),并在 AppDelegate.accessibilityPermissionDidChange 中授权后自动重新注册 AX 观察者。install.sh 维持即席签名不动,末尾补充授权步骤与持久化签名建议。
- 将 install.sh 改为自签名:用稳定自签证书(默认 SelectedAI Local)在构建后 codesign --options runtime --entitlements 签名,使辅助功能(TCC)授权在重建后保留;无证书时回退即席签名并提示。原因:即席/未签名按二进制哈希记录授权,重建即失效。另:带 entitlements 后 com.apple.security.automation.apple-... 生效,BrowserURLFetcher 读浏览器URL功能恢复。
