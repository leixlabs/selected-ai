## 里程碑 1：项目脚手架 & 应用生命周期

> 目标：一个能常驻菜单栏、无 Dock 图标、可退出的最小可运行应用。

### 1.1 Xcode 项目初始化
- [ ] 创建 macOS App 项目（Swift, SwiftUI lifecycle）
- [ ] 配置 `Info.plist`：`LSUIElement = YES`（隐藏 Dock 图标）
- [ ] 设置最低部署目标 macOS 15+
- [ ] 配置本地开发者签名（不公证）
- [ ] 配置 `Entitlements`：Accessibility、AppleScript 权限声明

### 1.2 菜单栏常驻
- [ ] 使用 `NSStatusItem` 创建菜单栏图标（SF Symbol `text.cursor` 占位）
- [ ] 实现菜单栏点击弹出菜单：
  - [ ] 启用 / 禁用划词工具栏（总开关，可直接切换）
  - [ ] "设置…" 菜单项（占位）
  - [ ] "关于 SelectedAI" 菜单项
  - [ ] "退出 SelectedAI" 菜单项

### 1.3 登录时启动
- [ ] 使用 `SMAppService.mainApp` 实现登录启动（默认关闭）
- [ ] 在设置中提供开关，状态持久化到 `UserDefaults`

### 1.4 辅助功能权限引导
- [ ] 首启检测 Accessibility 权限状态
- [ ] 未授权时弹出引导对话框，引导用户到系统偏好设置
- [ ] 未授权时禁用划词功能，菜单栏开关置灰

## 里程碑 3：选区检测

> 目标：能跨应用检测到用户的文本选区，获取选区文本和屏幕坐标。

### 3.1 Accessibility 监听
- [ ] 使用 `AXObserver` 监听 `AXSelectedTextChanged` 通知
- [ ] 监听前台 App 切换（`NSWorkspace` 通知），动态注册/注销 Observer
- [ ] 收到通知后读取焦点元素的 `AXSelectedText` 属性
- [ ] 读取选区屏幕边界坐标（`AXSelectedTextRange` + `AXBoundsForRange`）

### 3.2 选区稳定 & 过滤
- [ ] 去抖动：选区变化后等待 200ms 稳定再触发
- [ ] 最小字符过滤：选区 ≥ 2 个字符
- [ ] 选区消失立即清除（无延迟）
- [ ] 选区文本原样保留空白和换行

### 3.3 禁用规则检查
- [ ] 检查总开关状态
- [ ] 按 Bundle ID 检查当前 App 是否被禁用
- [ ] 浏览器 URL 获取（AppleScript）
  - [ ] Safari: `tell application "Safari" to get URL of current tab of front window`
  - [ ] Chrome: 对应 AppleScript 命令
  - [ ] 首次调用时触发 AppleScript 自动化权限请求
- [ ] 按规范化域名 + 子域匹配检查网站禁用规则
- [ ] App 禁用优先于网站规则
- [ ] 非 Safari/Chrome 浏览器：工具栏正常，网站禁用不生效

### 3.4 选区坐标降级策略
- [ ] 选区边界不可得时，尝试获取光标位置（`AXInsertionPointBounds`）
- [ ] 光标位置也不可得时，定位到焦点窗口中央
