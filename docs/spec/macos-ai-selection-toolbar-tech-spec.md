# SelectedAI — macOS AI 划词工具栏 Tech Spec

## 1. Summary

构建 macOS 15+ 原生菜单栏工具（Swift + SwiftUI/AppKit）。通过 Accessibility API 读取跨应用文本选区，选区至少 2 个字符且稳定 200ms 后，在选区上方显示划词工具栏。点击技能后工具栏消失，在选区下方弹出结果浮窗。UI 采用 macOS 原生材质、SF Symbols。仅供个人使用，本地 Xcode 编译运行，不签名、不公证、不分发。

首发重点验收应用：TextEdit、Notes、Preview、Safari、Chrome；其它支持 Accessibility 选区的 App 尽力兼容。

---

## 2. 应用生命周期

- 仅菜单栏常驻，无 Dock 图标。支持登录时启动，默认关闭。
- 菜单栏图标使用 SF Symbol 占位（如 `text.cursor`），后续替换自定义图标。
- 菜单栏图标点击弹出菜单：
  - 启用/禁用划词工具栏（总开关，可直接切换）
  - 设置…
  - 关于 SelectedAI
  - 退出 SelectedAI
- 首启显示辅助功能权限引导；未授权时工具栏不可用。
- Safari/Chrome 的 AppleScript 自动化权限按首次需要时请求。

---

## 3. 选区检测

- 使用 `AXObserver` 监听 `AXSelectedTextChanged` 通知（事件驱动，不轮询）。
- 收到通知后读取焦点元素的选区文本和屏幕边界坐标。
- 选区至少 2 个字符且稳定 200ms 后显示工具栏。
- 选区消失后工具栏**立即消失**，无延迟。
- 选区文本原样保留空白和换行。

---

## 4. 工具栏

### 4.1 窗口行为

- 使用 `NSPanel` + `nonactivatingPanel` 样式，不夺取原应用焦点，选区保持不变。
- 定位在**选区上方**居中；空间不足时显示在选区下方；始终限制在选区所在屏幕内。
- 多显示器：工具栏跟随选区所在的屏幕显示。
- 选区边界不可得时，退而求其次尝试获取光标位置，再不行定位到焦点窗口中央。

### 4.2 视觉样式

- **始终深色背景**，白色文字和图标（不跟随系统主题），确保在任何应用上方都有足够对比度。
- 胶囊形状浮动条，参考豆包截图布局。

### 4.3 技能按钮

- 默认技能顺序：翻译、复制、朗读、总结、解释。用户可在设置中拖拽排序。
- 前 5 项常驻显示，其余进入"…"溢出菜单。
- "…"菜单额外提供：
  - "在此应用中禁用"
  - "在此网站中禁用"（仅 Safari/Chrome 成功读取 URL 时显示）
  - "更多设置…"（打开设置窗口）

### 4.4 点击技能后

- 工具栏立即消失。
- 复制：静默复制选区原文到剪贴板，无反馈提示。
- 朗读：使用 `AVSpeechSynthesizer` 系统语音朗读选区原文，语言自动判断，提供播放/停止切换。
- 翻译、总结、解释、自定义 Prompt 技能：在选区下方弹出结果浮窗，调用当前活动 LLM Provider。

---

## 5. 结果浮窗

### 5.1 窗口行为

- 定位在**选区下方**；始终限制在选区所在屏幕内。
- 固定宽度 **420pt**，高度自适应内容，最大高度不超过屏幕可用高度的 **50%**，超出后内部滚动。
- 支持通过顶部拖动手柄拖动重新定位（固定和未固定状态均可）。
- 未固定时：点击浮窗外任意位置或按 Esc 关闭。
- 固定（📌）时：点击外部不关闭，保持显示。
- 未固定浮窗触发新任务时取消旧请求；固定浮窗可并行继续。
- 固定结果仅在本次运行中保留，退出即清空。

### 5.2 视觉样式

- **跟随系统深浅色**主题。
- 使用 macOS 原生材质（`NSVisualEffectView`）。

### 5.3 结果渲染

- 使用 **WKWebView** 流式渲染 Markdown（轻量 HTML 模板 + JS Markdown 库）。
- 支持常见文本结构、代码块（带语法高亮）和链接；不执行 HTML/脚本。
- 深浅色主题切换通过 CSS 实现。
- 复制结果时输出纯文本。

### 5.4 浮窗控件布局

- **右上角**：📌 固定/取消固定按钮
- **左侧底部**：朗读/停止朗读、复制结果
- **右侧底部**：重试、停止生成（流式输出中才显示）
- **最底部**：追问输入框 + 发送按钮
- 朗读按钮：朗读 AI 返回的结果文本，语言自动判断。

### 5.5 停止生成

- 流式输出中显示"停止生成"按钮。
- 停止后**保留已接收的部分结果**，用户可复制、朗读、重试。

### 5.6 翻译技能的特殊 UI

- 结果浮窗顶部显示语言切换：中文 / 英文两个按钮。
- 默认目标语言为中文；用户切换后持久化记住上次选择。
- 源语言始终自动检测，不可选。

---

## 6. 追问（连续对话）

- 追问携带原选区、技能指令和完整当前会话。
- 消息结构：
  - `system`：技能 Prompt（含 `{selection}` 替换后的原选区文本），仅出现一次。
  - `user` → `assistant` → `user` → `assistant`…：正常多轮对话。
- 不截断上下文；超上下文限制时在浮窗中展示 Provider 错误。

---

## 7. 技能体系

### 7.1 内置技能（不可编辑、不可删除）

| 技能 | 行为 | 调用 AI |
|------|------|---------|
| 翻译 | 调用 LLM，自动检测源语言，翻译为目标语言（中/英切换） | ✅ |
| 复制 | 静默复制选区原文到剪贴板 | ❌ |
| 朗读 | `AVSpeechSynthesizer` 朗读选区原文 | ❌ |

### 7.2 预置 Prompt 技能（可编辑、可删除）

| 技能 | 默认 Prompt 概要 |
|------|------------------|
| 总结 | 核心结论 + 3–5 要点 |
| 解释 | 通俗中文结合上下文解释 |

### 7.3 自定义 Prompt 技能

- 字段：名称（最长 20 字符）、SF Symbol 图标（从预设 20–30 个精选图标中选择）、Prompt 文本。
- Prompt 必须包含 `{selection}` 占位符，缺失不可保存。
- 支持创建、编辑、删除。删除立即生效并提供短暂撤销（Toast）。

---

## 8. Provider 配置

### 8.1 数据模型

- 支持保存多条 Provider 配置，指定一条为全局活动配置；所有 AI 技能共用该活动配置。
- 字段：
  - 显示名称
  - 协议：OpenAI / Anthropic
  - API Base URL（可带 `/v1`，应用规范化尾部斜杠并补全路径）
  - Token（存 macOS Keychain）
  - Model ID（自由文本，不拉取模型列表）
- 不支持自定义 HTTP Header。

### 8.2 API 协议

| 协议 | 端点 | 格式 |
|------|------|------|
| OpenAI | Chat Completions API (`/v1/chat/completions`) | SSE 流式 |
| Anthropic | Messages API (`/v1/messages`) | SSE 流式 |

### 8.3 测试连接

- 发送一个简短的 chat completion 请求（如 "Hi"），非流式，超时 10 秒。
- 显示认证、网络、模型或协议错误的具体信息。

### 8.4 无 Provider 状态

- AI 技能显示可读错误并提供直达设置入口。
- 保留当前选区和待执行操作，用户配置完 Provider 后可继续。

---

## 9. 网络与错误处理

- 连接超时：**10 秒**。
- 流式响应中两个 chunk 之间最大间隔：**30 秒**，超过判定超时。
- 错误信息直接在结果浮窗中展示，用户可点击重试。
- 客户端不设文本或会话长度上限。

---

## 10. 禁用规则

- **总开关**：控制"选中文本时显示工具栏"。
- **禁用 App**：通过原生应用选择器添加，按 Bundle ID 存储；首启列表为空。
- **禁用网站**：接受域名或完整 URL，保存为小写规范化域名，匹配该域及所有子域。
- **浏览器 URL 获取**：使用 AppleScript，首发支持 Safari 和 Chrome。
  - Safari: `tell application "Safari" to get URL of current tab of front window`
  - Chrome: 对应 AppleScript 命令
  - 其他浏览器：工具栏正常工作，网站禁用规则不生效，仅按 App 规则。
- App 禁用优先于网站规则；无法读取网页 URL 时仍按 App 规则运行。

## 11. 设置界面

### 11.1 入口

- 菜单栏图标菜单 → "设置…"
- 工具栏"…"菜单 → "更多设置…"

### 11.2 窗口

- 独立标准 macOS 窗口（非 popover）。
- 支持中英文，跟随 macOS 系统语言。
- 首发不支持配置导入/导出。

### 11.3 Tab 结构

| Tab | 内容 |
|-----|------|
| **通用** | 总开关、登录时启动、禁用 App 列表、禁用网站列表 |
| **技能** | 技能列表（拖拽排序）、编辑/删除、底部"+ 新建技能"按钮 |
| **Provider** | Provider 列表、新建/编辑/删除、测试连接、设置活动 Provider |

---

## 12. 数据存储与隐私

### 12.1 存储方案

| 数据类型 | 存储方式 |
|----------|----------|
| 简单开关（总开关、翻译语言偏好、登录启动等） | `UserDefaults` |
| 技能列表、排序、Provider 配置元数据、禁用规则 | JSON 文件（`~/Library/Application Support/SelectedAI/`） |
| API Token | macOS Keychain |
| 会话、浮窗状态、结果 | 仅内存 |

### 12.2 隐私

- 不保存选区文本、请求、回复、会话历史。
- 不发送遥测或调试日志。
- 仅内存保留当前运行中的浮窗状态、结果与待重试请求。

---

## 13. 键盘支持

- `Esc`：关闭未固定浮层。
- `Tab`：焦点导航。
- `Enter` / `Space`：激活控件。
- 首发不做全局快捷键。

---

## 14. 技术架构

### 14.1 技术栈

| 层 | 技术 |
|---|------|
| 最低系统 | macOS 15+ |
| 语言 | Swift |
| 并发 | Swift Concurrency（async/await、Actor） |
| 菜单栏、浮窗管理、Accessibility | AppKit（`NSPanel`、`AXObserver`） |
| 设置界面 | SwiftUI |
| Markdown 渲染 | WKWebView（HTML 模板 + JS 库） |
| TTS | `AVSpeechSynthesizer` |
| 浏览器 URL | AppleScript（`NSAppleScript`） |
| 分发 | 本地 Xcode 开发者签名，不公证 |

### 14.2 关键窗口类型

| 窗口 | 类型 | 激活行为 |
|------|------|----------|
| 工具栏 | `NSPanel` + `nonactivatingPanel` | 不夺取焦点 |
| 结果浮窗 | `NSPanel` | 可激活（追问输入需要键盘焦点） |
| 设置窗口 | `NSWindow` | 标准窗口 |
